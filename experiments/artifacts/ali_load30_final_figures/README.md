# Final AliStorage 30% load sweep

This artifact contains the five-seed GUARD/HPCC/Homa comparison used to
regenerate the initial 30% load panels.  All controls were frozen before seeds
21--25, all 15 runs completed, and all admission gates passed.  GUARD's mean
FCT is statistically tied with Homa, while its P95 FCT, P95/P99 slowdown, and
mean/maximum queue measurements are lower.
