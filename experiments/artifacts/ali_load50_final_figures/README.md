# Final AliStorage 50% load sweep

This artifact contains the five-seed GUARD/HPCC/Homa comparison used to
regenerate the initial 50% load panels.  All controls were frozen before seeds
21--25, all 15 runs completed, and all admission gates passed.  GUARD lowers
P95 FCT and mean queue relative to Homa, but its mean and P99 FCT are higher.
The retained result bounds the optimized design rather than selecting only a
favorable load.
